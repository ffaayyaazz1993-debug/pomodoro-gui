# Pomodoro GUI

A beautiful Pomodoro timer GUI with task management, built with Python and Tkinter.

## Features

- **Per-task timer cards** — each task has its own timer with progress bar
- **Eisenhower priority matrix** — Q1-Q4 priority levels
- **Sub-tasks** — add sub-tasks to any task
- **Apple glass theme** — light and dark mode support
- **Scheduling** — schedule recurring pomodoros via Windows Task Scheduler
- **Notes** — add notes to tasks
- **Statistics** — track pomodoros and time spent
- **Sound notifications** — beep when timer completes
- **Auto-chain** — automatically start next task when timer finishes

## Installation

```bash
pip install -e .
```

## Usage

```bash
pomodoro-gui
```

Or run directly:

```bash
python pomodoro_gui.py
```

## Data

- Todos: `~/pomodoro_data.json`
- Log: `~/pomodoro_log.txt`
